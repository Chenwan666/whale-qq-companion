# 部署经验与排障

这些经验来自持续部署中遇到的问题，整理为通用规则，不包含原作者的聊天、账号、使用数据或角色设定。

| 现象 | 先查什么 | 处理方式 |
|---|---|---|
| 启动停住，没输出 | 当前进度步骤、下载网络、日志更新时间 | 首次依赖下载可能较慢；保留逐步进度。不要反复双击多个窗口 |
| npm ci 报锁文件不一致或缺 peer dependencies | 发布包是否保留 `.npmrc` 与 lockfile | 本包沿用锁定依赖所需的 legacy-peer-deps 设置；不要漏复制隐藏文件，不能只拿 package.json 重装 |
| 脚本乱码、路径有空格就失败 | PowerShell 文件编码、路径引号 | 启动器使用 UTF-8 BOM；保持整个目录一起解压，勿只复制一个 cmd |
| QQ 有消息但没回复 | 机器人是否登录、OneBot 是否接通、白名单、AI模型设置 | 控制台登录成功不等于QQ已接入；先定位链路，再考虑模型 |
| 新好友/新群不回复 | 管理员身份、会话许可与功能开关 | 为具体会话授权，不能把普通账号加入管理员 |
| “工具不可用”或 403 | 本版本是否包含该功能、工具清单是否刷新、令牌是否随会话传递 | 不靠反复催促；本包无手机功能，精简版也无语音工具 |
| 改工具后仍按旧规则 | DSH/MCP 是否仍加载旧 schema | 完整停止本包后重新启动，刷新工具清单；后台错误不能算模型“不会用” |
| 搬目录后会话冲突 | 任务会话是否绑定旧工作目录 | 独立运行目录与按目录区分的任务会话，旧配置不直接覆盖新包 |
| 大段重复输入很贵 | 实际请求量、缓存命中、工具 schema、上下文长度 | 看账本证据；高峰可能改变单价，但不能解释所有费用增长 |
| 没派任务也有费用 | 主动搭话、归档、自动研究、其他共享 Key 程序 | 逐项分类；本包默认关闭付费后台行为，不将所有内部请求叫黑话学习 |
| 说“记住了”却忘记 | 工具是否成功写入、会话归属、是否检索最新值 | 先写数据库再答应，覆盖同主题更正；临时任务不能变永久偏好 |
| 语音生成成功却没收到 | 合成记录、上传、消息回读 | 生成、提交、确认分开；结果不明先读回，不能盲目重发 |
| 在线声音 403 | 网络路径、服务权限、音色资源匹配 | 本地声音与云端分别检查；不擅自改防火墙或代理，不反复扣费测试 |
| Word/PDF/ZIP 读不了 | 可选 Python 依赖、文件类型、扫描图或加密限制 | 菜单5安装依赖；只报告实际已读范围，不把目录列表当全文 |
| 下载后只发了链接 | 是否拿到真实文件、发送工具收到文件ID | 下载与发送分开验证，文件名不能替代附件证据 |
| 撤回、点赞、头衔显示成功却没生效 | 平台支持、真实群主权限、平台返回与回读 | 区分已提交与已确认；不把工具“没有抛错”当完成 |
| 停止后仍在执行 | 派发队列、在途模型、后台进程 | 先停后续派发，再取消在途工作，保存结果，核对本包服务退出 |

不要用同一套逻辑混淆好友私信、消息通知回复和指定帖子评论。公开网页版与手机 App 的登录状态、实名要求与可访问内容也可能不同。本分享包不包含手机能力，因此需要 App 才能完成的任务应如实说明。

发布类任务用真实 URL、目标身份、一次性请求 ID 和发送后证据。安全页面、实名认证、验证码或平台限权由用户按正常流程完成，不通过绕过校验“修复”。任务取消、超时和未知结果不能偷偷换 ID 续跑。

提交问题时建议提供：版本（Lite/Ultimate）、当前步骤、错误文字、脱敏日志片段与发生时间。不要发整个 state、config、浏览器目录或 Key。只读诊断不会向 QQ 发消息，也不会调用付费模型。
