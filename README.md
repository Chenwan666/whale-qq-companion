# 🐳 小鲸鱼 · QQ Companion

一个在 Windows 本地运行的 QQ AI 聊天伙伴：私聊与群聊、分会话记忆、表情、网页与文件工具，以及鲸鱼主题的管理小窝。

**本仓库源码对应终极版：含可选语音，不含手机操控。** 精简版不含语音。两版都从空白配置开始，使用通用鲸鱼角色卡，接收者配置自己的 QQ、模型 API 和接入端。

[下载精简版 / 终极版](https://github.com/Chenwan666/whale-qq-companion/releases/latest) · [操作与配置](操作与配置.md) · [经验与排障](经验与排障.md) · [验证范围](验证记录.md)

## 五步启动

1. 从 Releases 下载所需 ZIP，并完整解压到固定目录；也可下载本仓库源码获得终极版。
2. 安装 Node.js 24 LTS。文档解析、云端语音可选安装 Python 3.11/3.12。
3. 自行安装、启动并登录支持 OneBot v11 HTTP 与正向 WebSocket 的 QQ 接入端。
4. 双击根目录唯一入口 **启动小鲸鱼.cmd**，回车启动；首次下载依赖后，在本地设置页填写自己的管理员 QQ、API Key 与接入参数。
5. 等待分步进度完成，进入小窝确认连接状态。首次仅开放管理员私聊，其他用户和群需要自行授权。

同一个启动入口：菜单 **2 停止**、**3 本地配置**、**4 只读诊断**、**5 安装可选依赖**。小窝也有停止按钮；关闭网页不等于停止服务。

## 记忆与费用

不同私聊和群聊分别保存记忆、偏好与约定，共享已审核的表情素材。明确要求记住的内容可由聊天工具直接保存，支持检索、更正和删除。

低频工具按需查询，减少每轮重复携带的工具说明；自动学习、定时整理和主动任务默认关闭，后台学习有去重、配额与失败退避。费用报表为本地估算，实际费用以服务商账单为准。

## 分享边界

本包是源码部署包，不是免安装 EXE，不提供模型额度，也不捆绑 QQ、SnowLuma、模拟器、个人音色或翻唱模型。没有原作者的 API、私人角色卡、聊天记录、记忆或登录态。Windows x64 是启动器的目标环境。

首次运行前可执行 `node distribution/verify-package.mjs` 校验源文件。使用后产生的 `config.json`、`state/`、运行环境和日志都可能含私人资料，**请分享原始 Release ZIP，勿重新打包已使用目录**。

## 开始

1. 将整个 ZIP 解压到一个固定目录，例如你自己选择的非系统盘文件夹；不要在压缩包预览中运行。
2. 安装 Node.js 24 LTS。Windows 10/11 x64 是本包的目标环境，其他系统未提供启动器支持。
3. 自行安装并启动 QQ 接入端。支持 OneBot v11 的 HTTP 与正向 WebSocket；SnowLuma 的安装、登录、加载由你完成，本包只连接已有服务。
4. 双击根目录唯一入口 **启动小鲸鱼.cmd**，按回车启动。首次会下载依赖并打开本地设置窗口，填写你自己的管理员 QQ、模型 API Key 和接入端 Token。
5. 启动完成后打开小窝。新安装只许可管理员自己的私聊；其他人和群聊需要你逐个开放。先核对机器人接入状态，再发送一条普通测试消息。

默认采用 DeepSeek 官方服务，模型为 `deepseek-flash`。使用别的服务商或模型时，应在你自己的 DSH 后台配置服务商，并同步 `qq-bridge/config.json` 的 provider/model；不能只更改模型显示名称。

语音和文档解析的可选依赖：启动菜单选择 **5**。需要先安装 Python 3.11/3.12。终极版本地语音先用 Windows 已安装的声音跑通；云端音色另填自己的语音 API Key，不包含任何人的私有音色。

阅读 **操作与配置.md**、**经验与排障.md**、**分享与升级.md** 后再扩大白名单或启用后台任务。
